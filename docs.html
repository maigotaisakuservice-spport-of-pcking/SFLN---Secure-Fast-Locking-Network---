SFLN 開発者ドキュメント

SFLN (Secure Fast Locking Network) をアプリケーションに統合するためのガイドです。

概要

SFLN SDK を使用することで、開発者は複雑な暗号化や P2P 経路制御を意識することなく、セキュアな高速通信機能をアプリに組み込むことができます。

通信はローカルで動作する SFLN クライアント（デーモン）を介して行われ、12,000桁の独自暗号と 1KB 分割転送が自動的に適用されます。

SDK 存在確認ロジック (Verification Logic)

SDK は動作前に、ユーザーの環境に SFLN クライアントアプリがインストールされ、正しく実行されているかを確認する必要があります。

SFLN クライアントは管理者権限で実行されると、ローカルホストの ポート 49000 でヘルスチェック用サーバーを起動します。SDK はこのポートにリクエストを送り、応答を確認します。

// 内部的なチェックの流れ
async function checkSFLN() {
    try {
        const response = await fetch('http://localhost:49000/status');
        return response.ok;
    } catch (e) {
        return false;
    }
}

JavaScript SDK

Webブラウザや Node.js 環境で利用可能です。デモページなどで実際に使用されています。

1. ブラウザでの利用 (CDN/直接リンク)

HTMLに以下のスクリプトタグを追加するだけで、SFLNClientJS が利用可能になります。

<!-- SFLN Library の読み込み -->
<script src="https://maigotaisakuservice-spport-of-pcking.github.io/SFLN---Secure-Fast-Locking-Network---/sfln/js-library/sfln.js"></script>

2. NPM での利用

モダンな開発環境では NPM パッケージとしてインストールできます。

npm install @sfln/sdk

基本コード例

import { SFLNClient } from '@sfln/sdk';

const sfln = new SFLNClient();

// 存在確認と接続
if (await sfln.verifyPresence()) {
    await sfln.connect('wss://sfln-server.pdg.f5.si');

    // データの送信 (1KB単位の分割と暗号化はSDKが自動処理)
    await sfln.send("Hello, secure world!", "TARGET_NODE_ID");
}

Python SDK

デスクトップアプリやサーバーサイドでの統合に最適です。

基本コード例

from sfln.library import SFLNLibrary

sdk = SFLNLibrary()

# クライアントアプリの起動確認
if sdk.is_daemon_running():
    # 大容量ファイルの転送 (自動分割 & 12,000桁暗号)
    sdk.send_file("large_data.zip", target_id="XYZ-123")
else:
    print("SFLN Client is not running.")

アーキテクチャ

SFLN は「自律型メッシュ」と「中央リレー」のハイブリッド構成をとります。

  • Edge AI Routing: 各ノードがレイテンシを学習し、最短経路を選択。
  • AES-GCM-SFLN: 標準の AES-GCM に、動的な 12,000 桁のカスタムシードを組み合わせた独自暗号。
  • Self-Healing: 不安定なノードを自動検知し、瞬時に経路を切り替えます。

ユースケース

機密データ共有

法務・金融などの極めて高い秘匿性が求められる文書を、既存のクラウドを介さず直接相手に届けます。

分散型バックアップ

データを細分化して複数の信頼できるノードに分散配置することで、災害時でもデータを復元可能にします。

リモートメンテナンス

VPN を構築することなく、グローバル IP のない環境にある機器へ安全にアクセスし、制御コマンドを送受信します。
